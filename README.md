# Disney Vintage

A synchronized vintage Disney channel for classic animation and television from 1928 through 2000.

- Daily lineup changes at midnight in the viewer's local time.
- Every viewer sees the same program moment for that day.
- Full classic episodes come from Disney Kids / Disney Channel Animation uploads.
- The channel excludes post-2000 programming and does not schedule unverified movie uploads.
- Includes the shared channel remote, TV guide, Picture-in-Picture support, sharing, and StarCoin wallet progress.

Live site: https://www-infinity4.github.io/Disney/
